# photo/ —— 项目自带素材（**不是**商家上传的图）

这里放的是**项目自带的兜底素材**。前端取图规则永远是：

> **先看接口返回的图（商家/运营在后台传的），接口没给才回落到这个目录。**

所以这个目录里的图，只决定「后台还没配图时页面长什么样」。
后台一旦配了图，这里放什么都看不见。

---

## 一、需要你自己配图的，只有这三个目录（都只在**商城首页 `/shop`**）

按首页从上到下的顺序：

### 1. `photo/shortcut/` —— 金刚区小图标

- **位置**：商城首页最上面那排小方块（「推荐位管理 → position=2」的位置），最多 8 个
- **比例 / 尺寸**：`1:1`，建议 **240 × 240**
- **没有图时**：显示一个线性 `tag` 图标 + 下面的分类名
- **占位块长什么样**：白色圆角方块 + 灰色小图标

### 2. `photo/category/` —— 分类卡图

- **位置**：首页「**按分类逛**」那一排分类卡，最多 12 张（每张是 4:5 竖图）
- **比例 / 尺寸**：`4:5`，建议 **600 × 750**
- **没有图时**：浅灰底 + 图标占位
- **数据来源**：`GET /api/mall/catalog/categories` 的分类；后端 `mall_category.icon` 有值就用后端的

### 3. `photo/product/` —— 商品卡兜底图

- **位置**：首页「**热销推荐**」和「**新品上架**」两个区块里的商品卡（4:5 竖图）
- **比例 / 尺寸**：`4:5`，建议 **800 × 1000**
- **没有图时**：浅灰底 + 图标占位
- **取图规则**：按**商品 id** 取池子里的第 `id % 张数` 张 —— 同一个商品永远同一张图，刷新不会跳

> **顺序怎么控制**：池子里按**文件名自然排序**取用（`2.jpg` 排在 `10.jpg` 前面）。
> 所以用 `01.jpg`、`02.jpg`… 编号即可，**文件名本身无所谓**。

---

## 二、为什么其他页面不吃这三个池子？

因为「本地兜底」只在首页开了。其它用到商品卡的地方（搜索、收藏、外卖首页、外卖店铺页）
用的是同一个 `MProductCard`，但**没开 `local-image`**，所以那些页面：

> **只在后台真的配了图时才显示图；没配就是灰底占位块，放 `photo/product/` 也没用。**

如果你希望它们也吃本地兜底，给对应页面的 `<MProductCard>` 加一个 `local-image` 属性即可（一行）。

## 四、插图（空态 / 404）—— `photo/illustration/`

放的是**内联 SVG 插图**（不是 `<img>`），目前 **9 张**，**32 处空态全部用上了**：

| 文件 | 用在哪 | 什么时候出现 |
| --- | --- | --- |
| `not-found.svg` | 404 页、商品不存在（商城/外卖商品页） | 路由或商品找不到 |
| `empty-cart.svg` | 商城 `/shop/cart`、外卖 `/food/cart`、店内点单结算 | 购物车为空 |
| `empty-order.svg` | 商城/外卖订单列表、订单不存在、骑手「我的配送」 | 没有订单/配送单 |
| `empty-favorite.svg` | 我的收藏 | 还没收藏过 |
| `empty-footprint.svg` | 我的足迹 | 还没浏览记录 |
| `empty-address.svg` | 收货地址（商城地址页/商城结算/外卖结算/外卖「我的」） | 还没添加地址 |
| `empty-review.svg` | 我的评价、商品评价区、订单去评价、后台评价管理 | 还没有评价 |
| `empty-search.svg` | 商城搜索无结果、外卖「没有匹配的商家」 | 搜不到 |
| `empty-data.svg` | 后台看板/分类、商家看板、骑手抢单池、外卖首页与店铺、首页推荐、结算未选中 | 通用「暂无数据」 |

用法就是给空态组件传一个名字（其它空态不传，仍走 64px 线性图标）：

```vue
<MEmpty image="empty-cart" icon="cart" title="购物车是空的" desc="去首页挑几件商品吧">
```

### 怎么加新插图（空收藏 / 搜索无结果 / 无商家…）

```bash
node scripts/import-illustration.mjs <你的.svg> --name empty-favorite
```

脚本会（细节看脚本顶部注释）：

1. **主色 → `currentColor`** —— 插图颜色跟着 `--m-accent`（品牌蓝）走，**不用出两套图**；
2. 深色 → 项目墨色 `#16130f`；
3. 去掉 `width/height`（保留 `viewBox`），尺寸交给 CSS；
4. 原图留档到 `photo/_source/illustration/`（不打包）。

> 新素材若用的是**别的色板**（不是 unDraw 那个 `#6c63ff`），先在脚本顶部的 `ACCENT` / `DARK` 数组里加一行。
> 改完**不用重启** dev server（HMR 会自刷）。

### 两个注意点

- **必须内联渲染**（`v-html`），不能用 `<img src>` —— 否则 `currentColor` 会变黑。
- 插图**按张懒加载**：每张 SVG 各自一个 chunk（2.8KB ~ 26KB），一个页面通常只用一张 → 只下那一张；不传 `image` 的页面一张都不下。

## 五、和「商家/运营上传的图」的区别

商家/运营在后台传的图**不会进这个目录** —— 它们传到 OSS，URL 存在数据库里：

| 数据 | 数据库字段 | 谁在哪里传 |
| --- | --- | --- |
| 商品主图 / 多图 | `mall_product.main_image`、`mall_product_image.image` | 运营后台 → 商品管理 → 编辑商品 |
| 分类图标 | `mall_category.icon` | 运营后台 → 分类管理 |
| 推荐位图 / 金刚区图 | `mall_banner.image`（position=1 轮播、2 金刚区） | 运营后台 → 推荐位管理 |
| 外卖店铺门头、外卖商品图 | `merchant.image`、`product.image` | 商家端 → 店铺设置 / 商品编辑 |

上传接口：`POST /api/mall/admin/file/upload`（运营）、`POST /api/merchant/file/upload`（商家）。

---

## 六、放图时注意

1. **扩展名要和真实格式一致**（别把 WebP/AVIF 存成 `.png`）—— 浏览器按扩展名取 MIME，写错可能不显示。
2. 文件名建议用 `01.jpg` 这种**纯英文数字**，避免中文/空格带来的 URL 编码问题。
3. 单张别太大（建议 ≤ 300KB），首页一次会加载不少张。
